# Livros pra Vida - Front-end

Páginas estáticas (HTML, CSS e JavaScript puro) publicadas no GitHub Pages.
A API (Ruby on Rails) fica no repositório LPV-API e roda no Render: https://lpv-api.onrender.com

- `index.html`: home
- `src/`: demais páginas (Catálogo, Comprar & Trocar, Chat, Minhas Estantes, Perfil, Carrinho, Termos...)
- `js/`: scripts compartilhados (`admin.js`, `estantes.js`, `validarCPF.js`)
- `css/`: estilos de cada página
